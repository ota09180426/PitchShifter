# YT Pitch Shifter

iPhone の Safari で YouTube を再生中に、**テンポを変えずにキーだけ**を ±6 半音（0.5 半音刻み）で変更するユーザースクリプトです。

- 対象: iPhone Safari（m.youtube.com）。PC の Chrome + Tampermonkey でも動作します
- YouTube 公式アプリには対応していません（外部から改変できないため）

## ファイル構成

| パス | 内容 |
|---|---|
| `yt-pitch-shifter.user.js` | 本体（このファイル 1 つだけを iPhone に入れます） |
| `test/dsp-test.html` | 音声処理の自動テスト（ピッチ精度・ステレオ・速度など） |
| `test/ui-smoke.html` | UI と音声経路の結合テスト |

## iPhone への導入

1. App Store で **Userscripts**（無料・オープンソース）をインストールします。
2. Userscripts アプリを開き、スクリプトの保存先フォルダを指定します（iCloud Drive 上のフォルダがおすすめです）。
3. iPhone の「設定」→「アプリ」→「Safari」→「機能拡張」→「Userscripts」をオンにします。iOS 17 以前は「設定」→「Safari」→「機能拡張」です。
4. iPhone の Safari で次の URL を開き、Userscripts の表示に従ってインストールします。

   https://raw.githubusercontent.com/ota09180426/PitchShifter/main/yt-pitch-shifter.user.js

   うまくいかない場合は、ファイルを手順 2 のフォルダに直接置いても構いません（メール等で受け取り、「"ファイル"に保存」で保存）。
5. Safari で `m.youtube.com` を開きます。初回はアドレスバー左のアイコン（「ぁあ」またはパズルピース）→ Userscripts から、このサイトでの実行を許可してください。
6. 画面右下に **「♭♯」ボタン**が出れば導入完了です。

## 使い方

1. 右下の「♭♯」ボタンをタップすると、パネルが開きます。
2. スライダー、または「−」「＋」ボタンでキーを変えます（0.5 半音刻み、−6〜+6）。
3. 「0 に戻す」で原曲キーに戻ります。

- キーを変えている間、ボタンは青色になり、現在の値（例: `+1.5`）が表示されます。
- 別の動画に移ると、キーは自動で ±0 に戻ります。
- 0.5 は四分音（50 セント）です。チューニングが半端にずれた音源に合わせるときに使えます。

## 仕様と制約

- **音が映像より約 0.1 秒遅れます。** 音声処理（フェーズボコーダ）の都合で、約 85ms の遅延と出力バッファ分が加わります。
- **全画面表示中はパネルが表示されません。** キーを変えるときは全画面を解除してください。
- **一度キーを変えた動画は、±0 に戻しても処理経路を通り続けます。** ±0 のときは原音と完全に同じ波形が出ます（遅延のみ）。経路から外したいときは、ページを再読み込みしてください。
- **最初にキーを 0 以外にした瞬間、音声が処理経路に切り替わります。** パネルを開いただけでは、元の音声に影響はありません。
- マナーモード（消音スイッチ）中でも音が出るように設定しています（iOS 16.4 以降）。

## うまく動かないとき

パネル下部の小さな文字が状態表示です。例: `Worklet · 48kHz · running · MSE · 処理中`

| 表示 | 意味 |
|---|---|
| `Worklet` / `ScriptProc` | 音声処理の方式。`ScriptProc` は代替方式で、動作はしますが音が途切れやすくなります |
| `running` 以外（`suspended` など） | 音声が停止しています。パネルをタップすると再開します |
| `MSE` / `HLS` / `URL` | YouTube 側の動画の配信方式。`HLS` の場合、iPhone では音声を取得できない可能性があります |
| `処理中` / `未接続` | 動画の音声がこのツールを通っているかどうか |

- **キーを変えたら音が消えた**: パネルに黄色い警告が出ている場合は、Safari が動画の音声を取得できていません。ページを再読み込みすると元に戻ります。そのときは状態表示の内容を開発者に伝えてください。
- **バックグラウンドから戻ったら音が出ない**: パネルか「♭♯」ボタンをタップしてください（iOS の制限で、タップしないと音声を再開できない場合があります）。

## 開発メモ

### 音声処理の方式

- 位相ロック付きフェーズボコーダ（Laroche & Dolson 方式）で、スペクトルのピーク単位に周波数を移動します。リサンプリングは使いません。
- FFT サイズ 4096、オーバーラップ 8（ホップ 512）。低音の分解能を優先した設定です。
- 左右のチャンネルに同じ位相回転をかけて、ステレオ定位を保ちます。
- AudioWorklet を優先して使います。読み込めない環境（ページの CSP 等）では ScriptProcessor に自動で切り替えます。
- 外部ライブラリは使っていません。

調整したい場合は、スクリプト冒頭の `CONFIG` を変更してください。

| 項目 | 効果 |
|---|---|
| `FFT_SIZE` | 2048 にすると遅延とアタックのにじみが減る代わりに、低音の精度が落ちます |
| `MIN` / `MAX` / `STEP` | キーの範囲と刻み |

### テストの実行（Windows）

DSP テストは、Chrome でそのまま開くと結果が表示されます。headless で実行する場合は次のとおりです。

```powershell
# リポジトリのルートで実行
$page = "file:///" + ((Resolve-Path test\dsp-test.html).Path -replace '\\', '/')
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --allow-file-access-from-files --dump-dom $page
```

`test/ui-smoke.html` は、Chrome で直接開いて結果を確認するのが簡単です（自動再生のため `--autoplay-policy=no-user-gesture-required` を付けて起動してください）。
